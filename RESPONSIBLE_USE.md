# Responsible Use Policy

## Purpose

PythonShellcodeInjector is published for the following purposes only:

- **Education** -- learning how shellcode loaders, memory management, and process injection work at a low level
- **Authorized security testing** -- penetration testing and red team engagements conducted with explicit written permission from the system owner
- **Capture the Flag (CTF)** -- use in CTF competitions and lab environments designed for security training
- **Security research** -- studying offensive techniques to improve defensive tooling, detection signatures, and incident response procedures

## Prohibited Uses

The following uses are strictly prohibited:

- Accessing, attacking, or disrupting any system, network, or service without explicit written authorization from the owner
- Distributing malware, ransomware, or any payload intended to cause harm

- Circumventing security controls in production environments without authorization
- Any activity that violates applicable local, state, national, or international law
